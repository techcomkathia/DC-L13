Métodos para criação de novos elementos filhos

A inseção de conteúdo dentro de um elemento HTML utiliza o innerHTML para escrever o conteúdo, ou seja, novas tags.Porém pode deixar o código mais dificil de ler e ocasionar erros

Por esse motivo, utilizamos o createElement para criar novos elementos e o appendChild para inserir novos elementos filhos dentro de um elemento pai
